# 🚀 پیام‌رسان تلگرام شبکه محلی (NetGram - Telegram LAN)

یک پیام‌رسان کامل، شیک و پرسرعت شبیه به تلگرام تحت شبکه محلی (LAN / Wi-Fi) بدون نیاز به اینترنت!

---

## 🌟 امکانات پروژه
- **بدون نیاز به اینترنت**: کاملاً تحت شبکه محلی (خانه، اداره، شرکت یا خوابگاه).
- **میزبانی و اتصال آسان (Host & Join)**: یک سیستم نقش سرور را ایفا کرده و سایر دستگاه‌ها (گوشی، لپ‌تاپ، تبلت) از طریق آدرس IP شبکه به آن متصل می‌شوند.
- **ثبت نام و ورود آسان**: امکان ثبت‌نام، ورود، تنظیم عکس پروفایل، نام نمایشی و بیوگرافی.
- **ارسال انواع رسانه**:
  - پیام‌های متنی به‌همراه ایموجی
  - ضبط و ارسال پیام صوتی (Voice Note) مستقیم از مرورگر
  - ارسال عکس، ویدیو و فایل‌های سند (PDF، Zip، Doc و...)
- **امکانات حرفه‌ای تلگرام**:
  - ایجاد گفتگوی خصوصی (Direct Chat)
  - ایجاد گروه (Group) و کانال (Channel)
  - واکنش به پیام‌ها با ایموجی (Emoji Reactions)
  - پاسخ به پیام (Reply) و سنجاق کردن پیام (Pin)
  - حذف پیام‌ها و نشانگر در حال تایپ (Typing Indicator)
  - حالت شب و روز (Dark / Light Theme)
  - رابط کاربری فارسی و راست‌چین (RTL) مطابق ظاهر تلگرام

---

## 🛠️ راهنمای اجرا و استفاده (بدون نیاز به گیت‌هاب)

نیازی به ورود به گیت‌هاب نیست! تمام فایل‌های برنامه روی سیستم شما آماده است. برای اجرا گام‌های زیر را دنبال کنید:

### ۱. نصب پیش‌نیازها و ساخت نسخه نهایی
در ترمینال پروژه دستورات زیر را وارد کنید:

```bash
# نصب وابستگی‌ها
npm install

# ساخت فایل‌های فرانت‌اند
npm run build:client
```

### ۲. اجرای سرور مسنجر
دستور زیر را جهت اجرای سرور وارد کنید:

```bash
npm start
```

### ۳. باز کردن برنامه
- **روی همین سیستم**: مرورگر خود را باز کرده و به آدرس `http://localhost:3000` بروید.
- **برای سایر دستگاه‌ها در شبکه محلی (گوشی، لپ‌تاپ دیگران)**:
  1. در بالای برنامه روی **آیکون شبکه (Server IP)** کلیک کنید تا آدرس IP سیستم شما نمایش داده شود (مثلاً `http://192.168.1.50:3000`).
  2. افراد دیگر در همان شبکه Wi-Fi یا کابل شبکه با وارد کردن این آدرس در مرورگر دستگاه خود وارد مسنجر می‌شوند.
  3. هر فرد ثبت‌نام کرده و شروع به چت، ساخت گروه یا ارسال فایل می‌کند!
