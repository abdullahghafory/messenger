# ساخت APK پیام‌رسان شبکه محلی

## ساخت APK با GitHub Actions (پیشنهادی برای گوشی)

1. این فایل ZIP را دانلود و از حالت فشرده خارج کنید.
2. تمام فایل‌ها و پوشه‌های داخل ZIP، از جمله پوشهٔ مخفی `.github`، باید مستقیماً در ریشهٔ مخزن GitHub قرار بگیرند؛ آن‌ها را داخل یک پوشهٔ اضافی قرار ندهید.
3. تغییرات را در شاخهٔ `main` ثبت کنید.
4. در مخزن GitHub وارد زبانهٔ **Actions** شوید و گردش‌کار **Build LAN Messenger APK** را اجرا کنید. اگر اولین بار است، ممکن است لازم باشد گردش‌کارها را فعال کنید.
5. منتظر سبز شدن اجرای workflow بمانید. سپس از صفحهٔ همان اجرا، بخش **Artifacts**، فایل `LAN-Messenger-debug-apk` را دانلود و ZIP آن را استخراج کنید.
6. فایل `app-debug.apk` را در گوشی نصب کنید. اگر اندروید اجازه خواست، نصب برنامه از همان منبع را فعال کنید.

## نکتهٔ مهم

این پروژه یک برنامهٔ اندرویدیِ پوسته‌ای برای باز کردن وب‌اپ پیام‌رسان موجود در شبکهٔ محلی است؛ خودش سرور PHP/MySQL را نصب یا اجرا نمی‌کند. سرور وب پیام‌رسان باید جداگانه در شبکه فعال باشد. بعد از نصب، نشانی IP و پورت سرور باید با شبکهٔ شما سازگار باشند.

## اگر ساخت شکست خورد

در GitHub وارد **Actions → اجرای ناموفق → Build** شوید و متن خطای قرمز و حدود 20 تا 40 خط آخر گزارش را کپی کنید یا تصویر بفرستید. فقط از روی خطای واقعی می‌شود مرحلهٔ بعد را دقیق اصلاح کرد. ساخته‌شدن ZIP به‌تنهایی به معنی ساخته‌شدن یا آزمایش‌شدن APK نیست.
